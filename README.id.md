Launcher Android yang merapikan aplikasi ke dalam laci berdasarkan kategori. Repositori ini hanya berisi file pemasangan aplikasi Android; tidak berisi kode sumber.

Memerlukan Android 11 atau yang lebih baru

## Pemasangan pertama

1. Buka halaman ini di ponsel, lalu ketuk tombol di atas untuk mengunduh StartLiteLauncher.apk.
2. Buka file yang diunduh. Jika muncul pesan bahwa aplikasi dari sumber tidak dikenal tidak dapat dipasang, ketuk "Setelan", izinkan sumber ini, lalu kembali dan lanjutkan.
3. Jika Play Protect menampilkan peringatan, ketuk "Detail selengkapnya" → "Tetap instal".
4. Setelah selesai, buka setelan StartLite lalu ketuk "Jadikan launcher default". Tombol Beranda akan membuka StartLite.

## Memperbarui ke versi baru

Cukup pasang versi baru di atas aplikasi saat ini, jangan copot pemasangan versi lama dulu. Memasang di atasnya akan menyimpan tata letak layar utama, kategori, dan setelan; jika dicopot dulu, semuanya akan hilang.

## Pertanyaan umum

- **"Aplikasi tidak terpasang" atau "paket bertentangan dengan paket yang ada"**: Aplikasi di ponsel tidak diunduh dari sini (tanda tangan berbeda). Ekspor cadangan di setelan StartLite pada "Cadangkan & pulihkan", copot aplikasi lama, pasang lagi, lalu pulihkan cadangan.
- **Tombol Beranda tidak membuka StartLite**: Buka setelan StartLite lalu ketuk "Jadikan launcher default", atau buka Setelan ponsel → Aplikasi → Aplikasi default → Aplikasi layar utama dan pilih StartLite Launcher.
- **Apakah StartLite memakai internet?**: Hanya untuk memeriksa versi baru saat Anda membuka setelan StartLite. Tidak ada data yang dikirim.
