ตัวเรียกใช้งาน Android ที่จัดแอปไว้ในลิ้นชักตามหมวดหมู่ ที่เก็บนี้มีเฉพาะไฟล์ติดตั้งแอป Android ไม่มีซอร์สโค้ด

**[ดาวน์โหลดสำหรับ Android](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [หน้าดาวน์โหลด (คำแนะนำตามภาษาของคุณ)](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [ทุกเวอร์ชัน](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

ต้องใช้ Android 11 ขึ้นไป

## ติดตั้งครั้งแรก

1. เปิดหน้านี้บนโทรศัพท์ แล้วแตะปุ่มด้านบนเพื่อดาวน์โหลด StartLiteLauncher.apk
2. เปิดไฟล์ที่ดาวน์โหลด หากมีข้อความว่าไม่สามารถติดตั้งแอปจากแหล่งที่ไม่รู้จัก ให้แตะ "การตั้งค่า" อนุญาตแหล่งนี้ แล้วกลับมาติดตั้งต่อ
3. หาก Play Protect แสดงคำเตือน ให้แตะ "รายละเอียดเพิ่มเติม" → "ติดตั้งต่อไป"
4. เมื่อติดตั้งเสร็จ ให้เปิดการตั้งค่า StartLite แล้วแตะ "ตั้งเป็นตัวเรียกใช้งานเริ่มต้น" จากนั้นปุ่มหน้าแรกจะพากลับมาที่ StartLite

## อัปเดตเป็นเวอร์ชันใหม่

ติดตั้งเวอร์ชันใหม่ทับแอปเดิมได้เลย ไม่ต้องถอนการติดตั้งเวอร์ชันเก่าก่อน การติดตั้งทับจะเก็บการจัดหน้าจอหลัก หมวดหมู่ และการตั้งค่าไว้ แต่ถ้าถอนการติดตั้งก่อน ทั้งหมดจะหายไป

## คำถามที่พบบ่อย

- **"ไม่ได้ติดตั้งแอป" หรือ "แพ็กเกจขัดแย้งกับแพ็กเกจที่มีอยู่"**: แอปในโทรศัพท์ไม่ได้ดาวน์โหลดจากที่นี่ (ลายเซ็นต่างกัน) ให้ส่งออกข้อมูลสำรองในการตั้งค่า StartLite หัวข้อ "สำรองและกู้คืน" ถอนการติดตั้งแอปเก่า ติดตั้งใหม่ แล้วกู้คืนข้อมูลสำรอง
- **กดปุ่มหน้าแรกแล้วไม่กลับมาที่ StartLite**: เปิดการตั้งค่า StartLite แล้วแตะ "ตั้งเป็นตัวเรียกใช้งานเริ่มต้น" หรือไปที่การตั้งค่าของโทรศัพท์ → แอป → แอปเริ่มต้น → แอปหน้าแรก แล้วเลือก StartLite Launcher
- **StartLite ใช้อินเทอร์เน็ตหรือไม่**: ใช้เพียงตรวจสอบเวอร์ชันใหม่เมื่อเปิดการตั้งค่า StartLite เท่านั้น และไม่ส่งข้อมูลใด ๆ
