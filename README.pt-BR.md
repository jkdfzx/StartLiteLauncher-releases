Um launcher para Android que organiza seus apps em uma gaveta por categorias. Este repositório hospeda apenas os arquivos de instalação do app para Android; não contém código-fonte.

**[Baixar para Android](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [Página de download (instruções no seu idioma)](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [Todas as versões](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

Requer Android 11 ou mais recente

## Primeira instalação

1. Abra esta página no celular e toque no botão acima para baixar o StartLiteLauncher.apk.
2. Abra o arquivo baixado. Se aparecer que apps de fontes desconhecidas não podem ser instalados, toque em "Configurações", permita esta fonte e volte para continuar.
3. Se o Play Protect mostrar um aviso, toque em "Mais detalhes" → "Instalar mesmo assim".
4. Quando a instalação terminar, abra os ajustes do StartLite e toque em "Definir como launcher padrão". O botão de início passará a abrir o StartLite.

## Atualizar para uma nova versão

Basta instalar a nova versão sobre o app atual, sem desinstalar a antiga. Assim o layout da tela inicial, as categorias e os ajustes são mantidos; se desinstalar antes, tudo isso será perdido.

## Perguntas frequentes

- **"App não instalado" ou "o pacote está em conflito com um pacote existente"**: O app do celular não foi baixado daqui (assinatura diferente). Exporte um backup nos ajustes do StartLite, em "Backup e restauração", desinstale o app antigo, instale novamente e restaure o backup.
- **O botão de início não abre o StartLite**: Abra os ajustes do StartLite e toque em "Definir como launcher padrão", ou vá em Configurações do celular → Apps → Apps padrão → App de início e escolha StartLite Launcher.
- **O StartLite usa a internet?**: Só para verificar se há uma nova versão quando você abre os ajustes do StartLite. Nenhum dado é enviado.
