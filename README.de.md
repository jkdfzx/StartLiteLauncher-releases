Ein Android-Launcher, der Ihre Apps in einer Schublade mit Kategorien ordnet. Dieses Repository stellt nur die Installationsdateien der Android-App bereit; es enthält keinen Quellcode.

**[Für Android herunterladen](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [Download-Seite (Anleitung in Ihrer Sprache)](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [Alle Versionen](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

Erfordert Android 11 oder höher

## Erstinstallation

1. Öffnen Sie diese Seite auf dem Smartphone und tippen Sie oben auf die Schaltfläche, um StartLiteLauncher.apk herunterzuladen.
2. Öffnen Sie die heruntergeladene Datei. Wenn Apps aus unbekannten Quellen nicht installiert werden können, tippen Sie auf „Einstellungen“, erlauben Sie diese Quelle und fahren Sie dann fort.
3. Wenn Play Protect eine Warnung anzeigt, tippen Sie auf „Weitere Details“ → „Trotzdem installieren“.
4. Öffnen Sie nach der Installation die StartLite-Einstellungen und tippen Sie auf „Als Standard-Launcher festlegen“. Die Home-Taste führt dann zu StartLite.

## Auf eine neue Version aktualisieren

Installieren Sie die neue Version einfach über die aktuelle App. Deinstallieren Sie die alte Version nicht vorher: Beim Überinstallieren bleiben Startbildschirm-Layout, Kategorien und Einstellungen erhalten, beim Deinstallieren gehen sie verloren.

## Häufige Fragen

- **„App nicht installiert“ oder „Paket steht in Konflikt mit einem vorhandenen Paket“**: Die App auf Ihrem Gerät stammt nicht von hier (andere Signatur). Exportieren Sie in den StartLite-Einstellungen unter „Sichern & wiederherstellen“ eine Sicherung, deinstallieren Sie die alte App, installieren Sie neu und stellen Sie die Sicherung wieder her.
- **Die Home-Taste führt nicht zu StartLite**: Öffnen Sie die StartLite-Einstellungen und tippen Sie auf „Als Standard-Launcher festlegen“, oder wählen Sie in den Einstellungen des Geräts unter Apps → Standard-Apps → Start-App StartLite Launcher aus.
- **Nutzt StartLite das Internet?**: Nur um beim Öffnen der StartLite-Einstellungen nach einer neuen Version zu suchen. Es werden keine Daten gesendet.
