アプリをカテゴリ別のドロワーで整理できる Android ランチャー。このリポジトリは Android アプリのインストールファイルのみを提供しており、ソースコードは含まれていません。

**[Android 版をダウンロード](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [ダウンロードページ（言語別の説明）](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [すべてのバージョン](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

Android 11 以上が必要です

## 初めてインストールする場合

1. スマートフォンでこのページを開き、上のボタンから StartLiteLauncher.apk をダウンロードします。
2. ダウンロードしたファイルを開きます。提供元不明のアプリはインストールできないと表示されたら「設定」をタップし、この提供元を許可してから戻って続行します。
3. Play プロテクトの警告が表示されたら「詳細」→「インストールする」をタップします。
4. インストールが終わったら StartLite の設定を開き、「デフォルトのランチャーに設定」をタップします。ホームボタンで StartLite が開くようになります。

## 新しいバージョンへの更新

新しいバージョンをダウンロードしたら、そのままインストールしてください。先に古いバージョンをアンインストールしないでください。上書きインストールならホーム画面の配置・カテゴリ・設定は保持されますが、アンインストールするとすべて失われます。

## よくある質問

- **「アプリはインストールされていません」「既存のパッケージと競合しています」と表示される**：端末のアプリはここからダウンロードしたものではありません（署名が異なります）。StartLite の設定の「バックアップと復元」でバックアップを書き出し、古いアプリをアンインストールして再インストールしてから復元してください。
- **ホームボタンを押しても StartLite が開かない**：StartLite の設定を開いて「デフォルトのランチャーに設定」をタップするか、端末の「設定」→「アプリ」→「デフォルトのアプリ」→「ホームアプリ」で StartLite Launcher を選んでください。
- **StartLite はインターネットを使いますか？**：StartLite の設定を開いたときに新しいバージョンがあるか確認するだけで、データは一切送信しません。
