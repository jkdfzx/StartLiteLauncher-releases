Un lanceur Android qui range vos applis dans un tiroir par catégories. Ce dépôt ne fournit que les fichiers d'installation de l'appli Android ; il ne contient pas de code source.

**[Télécharger pour Android](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [Page de téléchargement (instructions dans votre langue)](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [Toutes les versions](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

Nécessite Android 11 ou version ultérieure

## Première installation

1. Ouvrez cette page sur votre téléphone et touchez le bouton ci-dessus pour télécharger StartLiteLauncher.apk.
2. Ouvrez le fichier téléchargé. S'il est indiqué que les applis de sources inconnues ne peuvent pas être installées, touchez « Paramètres », autorisez cette source, puis revenez et continuez.
3. Si Play Protect affiche un avertissement, touchez « Plus de détails » → « Installer quand même ».
4. Une fois l'installation terminée, ouvrez les paramètres de StartLite et touchez « Définir comme lanceur par défaut ». Le bouton Accueil ouvrira alors StartLite.

## Mettre à jour

Installez simplement la nouvelle version par-dessus l'appli actuelle, sans désinstaller l'ancienne. L'installation par-dessus conserve la disposition de l'écran d'accueil, les catégories et les paramètres ; une désinstallation les ferait perdre.

## Questions fréquentes

- **« Application non installée » ou « le package est en conflit avec un package existant »**: L'appli de votre téléphone ne provient pas d'ici (signature différente). Exportez une sauvegarde dans les paramètres de StartLite, rubrique « Sauvegarde et restauration », désinstallez l'ancienne appli, réinstallez-la puis restaurez la sauvegarde.
- **Le bouton Accueil n'ouvre pas StartLite**: Ouvrez les paramètres de StartLite et touchez « Définir comme lanceur par défaut », ou allez dans Paramètres du téléphone → Applications → Applications par défaut → Application d'accueil et choisissez StartLite Launcher.
- **StartLite utilise-t-il Internet ?**: Uniquement pour vérifier s'il existe une nouvelle version quand vous ouvrez les paramètres de StartLite. Aucune donnée n'est envoyée.
