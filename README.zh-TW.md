**[下載 Android 版](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [下載頁（依語言顯示安裝說明）](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [所有版本](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

需要 Android 11 以上

## 第一次安裝

1. 用手機開啟這個頁面，點上方的按鈕下載 StartLiteLauncher.apk。
2. 開啟下載好的檔案。如果出現無法安裝不明來源應用程式的提示，點「設定」，允許這個來源，再返回繼續安裝。
3. 如果 Play 安全防護跳出提醒，點「更多詳細資料」→「仍要安裝」。
4. 安裝完成後開啟 StartLite 設定，點「設為預設啟動器」，按主畫面鍵就會回到 StartLite。

## 更新到新版

下載新版後直接安裝即可，不要先解除安裝舊版。覆蓋安裝會保留桌面版面、分類與設定；先解除安裝的話這些都會不見。

## 常見問題

- **出現「應用程式未安裝」或「套件與現有套件衝突」**：手機上的 App 不是從這裡下載的版本（簽章不同）。請先在 StartLite 設定的「備份與還原」匯出備份，解除安裝舊版、重新安裝後再還原。
- **按主畫面鍵沒有回到 StartLite**：開啟 StartLite 設定，點「設為預設啟動器」；或到手機的「設定」→「應用程式」→「預設應用程式」→「主畫面應用程式」選擇 StartLite Launcher。
- **StartLite 會連網嗎？**：只會在開啟 StartLite 設定時檢查有沒有新版本，不會傳送任何資料。
