**[下载 Android 版](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [下载页面（按语言显示安装说明）](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [所有版本](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

需要 Android 11 以上

## 首次安装

1. 用手机打开这个页面，点击上方按钮下载 StartLiteLauncher.apk。
2. 打开下载好的文件。如果提示无法安装未知来源的应用，点击“设置”，允许此来源，再返回继续安装。
3. 如果 Play 保护机制弹出提醒，点击“更多详情”→“仍然安装”。
4. 安装完成后打开 StartLite 设置，点击“设为默认启动器”，按主屏幕键就会回到 StartLite。

## 更新到新版本

下载新版本后直接安装即可，不要先卸载旧版本。覆盖安装会保留桌面布局、分类和设置；先卸载的话这些都会丢失。

## 常见问题

- **提示“未安装应用”或“软件包与现有软件包冲突”**：手机上的应用不是从这里下载的版本（签名不同）。请先在 StartLite 设置的“备份与恢复”导出备份，卸载旧版本、重新安装后再恢复。
- **按主屏幕键没有回到 StartLite**：打开 StartLite 设置，点击“设为默认启动器”；或在手机“设置”→“应用”→“默认应用”→“主屏幕应用”中选择 StartLite Launcher。
- **StartLite 会联网吗？**：只会在打开 StartLite 设置时检查有没有新版本，不会发送任何数据。
