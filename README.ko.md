앱을 카테고리별 서랍으로 정리하는 Android 런처. 이 저장소는 Android 앱 설치 파일만 제공하며 소스 코드는 포함되어 있지 않습니다.

**[Android용 다운로드](https://github.com/jkdfzx/StartLiteLauncher-releases/releases/latest/download/StartLiteLauncher.apk)** · [다운로드 페이지(언어별 안내)](https://jkdfzx.github.io/StartLiteLauncher-releases/) · [모든 버전](https://github.com/jkdfzx/StartLiteLauncher-releases/releases)

Android 11 이상 필요

## 처음 설치하기

1. 휴대전화에서 이 페이지를 열고 위의 버튼을 눌러 StartLiteLauncher.apk를 다운로드합니다.
2. 다운로드한 파일을 엽니다. 출처를 알 수 없는 앱을 설치할 수 없다는 안내가 나오면 "설정"을 눌러 이 출처를 허용한 뒤 돌아와 계속 설치합니다.
3. Play 프로텍트 경고가 나타나면 "세부정보 더보기" → "무시하고 설치"를 누릅니다.
4. 설치가 끝나면 StartLite 설정을 열고 "기본 런처로 설정"을 누릅니다. 이제 홈 버튼을 누르면 StartLite로 돌아옵니다.

## 새 버전으로 업데이트

새 버전을 다운로드한 후 바로 설치하세요. 이전 버전을 먼저 제거하지 마세요. 덮어서 설치하면 홈 화면 배치, 카테고리, 설정이 유지되지만, 먼저 제거하면 모두 사라집니다.

## 자주 묻는 질문

- **"앱이 설치되지 않았습니다" 또는 "기존 패키지와 충돌합니다"가 표시됨**: 휴대전화의 앱이 여기에서 다운로드한 버전이 아닙니다(서명이 다름). StartLite 설정의 "백업 및 복원"에서 백업을 내보낸 후, 이전 앱을 제거하고 다시 설치한 다음 복원하세요.
- **홈 버튼을 눌러도 StartLite로 돌아오지 않음**: StartLite 설정을 열고 "기본 런처로 설정"을 누르거나, 휴대전화의 "설정" → "애플리케이션" → "기본 앱" → "홈 앱"에서 StartLite Launcher를 선택하세요.
- **StartLite는 인터넷을 사용하나요?**: StartLite 설정을 열 때 새 버전이 있는지 확인할 때만 사용하며, 어떤 데이터도 보내지 않습니다.
